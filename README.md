# 🏨 Sistema de Gerenciamento de Hotel

Projeto desenvolvido para a disciplina de **Programação Orientada a Objetos (TCC00328)** do **Instituto de Computação** da **Universidade Federal Fluminense (UFF)**, sob orientação do **Prof. Carlos Alberto Soares Ribeiro**.

---

## 📌 Sobre o Projeto

O sistema tem como objetivo gerenciar os fluxos operacionais de um hotel, desde o cadastro dos hóspedes até o controle de consumo e finalização de hospedagens. O projeto aplica os pilares da Orientação a Objetos e boas práticas de arquitetura de software para garantir modularidade, legibilidade e manutenibilidade do código.

### 👥 Módulos e Entidades Principais

* **Clientes:** Cadastro, atualização e consulta das informações dos hóspedes.
* **Acomodações:** Gestão dos quartos/suítes, controle de disponibilidade e tipos de acomodação.
* **Hospedagens:** Check-in, check-out, associação de clientes a acomodações e controle do período de estadia.
* **Produtos:** Cadastro e controle de estoque do catálogo de produtos disponíveis no hotel.
* **Consumo:** Registro dos itens consumidos pelos hóspedes durante a estadia para composição do extrato final.
